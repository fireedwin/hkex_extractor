# 批次下載功能 — 架構說明與校正指南

## 這是什麼

`hkexnews_selenium.py` + `batch_download.py` 是原本 `hkexnews.py`(已證實無法運作)
的替代設計,用 Selenium 模擬瀏覽器操作 HKEXnews 網站。

**目前狀態:架構與純邏輯已驗證,網頁操作部分需要你在本機校正一次。**

---

## 已經驗證正確、不需要你再測的部分

這三塊不依賴連網,已經跑過測試:

- **`DateWindowPlanner`**:自動把查詢區間切成合法的時間窗
  (不指定公司時上限30天,指定公司時上限366天)
- **去重邏輯**:同一份文件如果在不同時間窗被重複查到,只保留一筆
- **檔名規則**:`股票代號_公司名_日期.pdf`

---

## 需要你在本機校正的部分(無法跳過,任何人寫都一樣)

`hkexnews_selenium.py` 裡的 `SELECTORS` class,每一行標了「← 待校正」的,
都是我根據 JSF 網站的**一般命名慣例**猜的,不是抄自真實頁面(因為我的環境連不上
HKEXnews,沒辦法親自打開頁面檢查)。

### 校正步驟

1. 安裝套件:
   ```bash
   pip install -r requirements.txt
   ```
   另外需要 Chrome 瀏覽器(大部分電腦應該都有)。Selenium 4.6+ 會自動抓對應版本的驅動程式,不用另外下載 chromedriver。

2. 用「顯示瀏覽器視窗」模式跑一次,肉眼看它卡在哪:
   ```bash
   python batch_download.py --stocks 00700 --from 20250101 --to 20251231 --show-browser
   ```

3. 程式報錯或瀏覽器沒有反應時,手動在瀏覽器打開
   `https://www1.hkexnews.hk/search/titlesearch.xhtml`,按 F12 開發者工具:
   - 點左上角箭頭圖示(Inspect Element),點擊你要找的欄位(股票代號輸入框、日期欄、搜尋按鈕...)
   - 對應到 `SELECTORS` class 裡卡住的那一行,把猜測的選擇器換成真實的

4. 改一個欄位,重跑一次,確認能推進到下一步,再改下一個。**不用一次全部改完**,程式設計成錯誤會清楚指出卡在哪一行。

## 兩個情境的取捨

| | 情境A:特定公司清單 | 情境B:整個市場 |
|---|---|---|
| 指令 | `--stocks 00700,09999` | `--whole-market` |
| 查詢區間上限 | 366天,一次查完 | 30天一個窗,長區間要拆很多次 |
| 面試demo適合度 | ✅ 適合 | ❌ 不建議現場示範 |
| 對網站的請求量 | 低 | 高,容易觸發防爬蟲機制 |

**面試建議:只準備情境A即可。** 情境B的程式碼已經寫好,可以在面試中作為
「我有想過旺季全市場規模的擴充方案,但基於對網站的禮貌性和穩定性考量,
demo階段先聚焦在情境A」——這句話本身就是加分的專業判斷。

## 這個檔案跟主流程怎麼接起來

目前 `batch_download.py` 是獨立的下載工具,下載完的PDF存在 `downloads/` 資料夾。
接下來要分析,一樣用原本的：

```bash
python batch_download.py --stocks 00700,09999 --from 20250101 --to 20251231
python run.py --pdf downloads/00700_Tencent_20250320.pdf --pdf downloads/09999_Sample_20250401.pdf
```

兩個工具刻意分開:下載是下載,分析是分析,任何一邊出錯不會拖垮另一邊,
除錯時也比較容易定位問題在哪一層。
